Agent × 大模型的上下文 × Skill —— 三者是什么关系？

个人学习仓库作业一 · 关系分析（配概念资料：agent.html / llm-context.html / skill.html）
概念关系个人理解生成日期 2026-09-06来源核查 2026-09-06

1一句话总览

我的归纳：Agent 决定"做什么"，上下文决定它"看得到什么"，Skill 决定它"会不会做"。上下文是 Agent 运行时的舞台与工作台；Skill 是被沉淀下来的经验，需要时通过"进入上下文"来影响 Agent 的每一步决策。

用一个职场类比帮助记忆：Agent 是被授权的员工，上下文是他面前的工作台（能摊开的资料有限，用完即收），Skill 是书架上的操作手册（平时不占桌面，遇到相关任务才翻开照着做）。员工干得好不好，既取决于桌面整理（上下文管理），也取决于手册质量（Skill 沉淀）。

2三者的定位对比

维度Agent（智能体）大模型的上下文（Context）Skill（技能）
本质能自主决策与行动的系统（模型+工具+循环）模型单次推理时可见的全部输入与窗口容量封装任务方法/经验的 SKILL.md 文件资产
生命周期一次任务的运行期一次请求的瞬时状态（无状态）跨会话长期存在，可版本管理与迭代
回答"谁在干活"执行者工作台/舞台经验与说明书
失效/边界需护栏，错误会在循环中放大窗口有限、中间信息易"迷失"、按 token 计费需触发加载，质量依赖编写与迭代

3关系一：上下文如何"驱动" Agent 工作

  • Agent 的每一次决策都基于上下文：模型没有独立于上下文的"当前状态"，它能"看到"的只有上下文里的内容（系统提示、历史、工具返回、检索结果）。因此上下文的内容与摆放方式，直接决定 Agent 每一步想什么、做什么。
  • 工具结果必须"回填"上下文：Agentic Loop 的循环动力来自"行动的结果被放回上下文 → 模型据此决定下一步"。没有这一环，Agent 就成了"盲人乱走"。
  • 上下文给 Agent 套上了边界：窗口有限、长上下文"中间迷失"（U 型曲线）、token 成本，都迫使 Agent 做上下文管理——摘要历史、检索精选、关键信息重锚。可以说会管上下文的 Agent，才是好 Agent。
  • "记忆"的本质是上下文的进出：Agent 的短期记忆＝当前窗口；长期记忆＝外部存储按需检索回来放进上下文。所谓"让 Agent 记住"，实际是"把信息放进它看得到的地方"。

4关系二：Skill 如何"沉淀"可复用任务知识

  • 经验从"对话里"沉淀到"文件里"：没有 Skill 时，同样的方法每次都要在对话里重新说一遍；写成 Skill 后，方法变成了可复用、可版本管理、可分享的资产——这是从"一次性知识"到"可沉淀知识"的关键一跃。
  • Skill 通过"进入上下文"来起作用：平时 Skill 只占几十 token 的元数据（name+description 常驻系统提示，让模型知道"有这本手册"）；任务相关时模型才读取 SKILL.md 全文、放进上下文，按手册行动。所以 Skill 是经验的载体，上下文是经验进入 Agent 决策的入口——这正解释了为什么 Skill 要设计"渐进式披露"：既要有用，又不能撑爆上下文。
  • Skill 还能反过来约束上下文质量：一份好的 Skill 会写明"输出结构、资料来源要求、自检清单"，等于给 Agent 的每次行动预置了质量标准，让上下文里的中间产物更规范。

5关系三：三者形成的"学习—执行—再沉淀"闭环

  1. 执行：Agent 接到目标，在上下文的"舞台"上观察信息、做决策、调工具。
  2. 反馈：工具/环境的结果回填上下文，推动下一轮循环，直到任务完成。
  3. 触发经验：当任务与某 Skill 相关，模型读取其 SKILL.md 全文进上下文，按"手册"行事——经验就这样影响了执行。
  4. 再沉淀：执行中发现的更好做法，被（人或 AI 协助）改进回 Skill 文件；Skill 随 Git 版本化，经验不断累积。

6我的个人判断（易错点与体会）

  • 最常被误解的是把三者当成一回事：有人以为"Agent 会自动学习进步"，其实模型参数不会因一次任务而改变——会"进步"的是 Skill 这类外部沉淀物，以及开发者对上下文/工具的设计。把"改进"寄托在正确的地方（外部知识资产 + 工程），而不是幻觉中的"模型自己变聪明"。
  • 理解三者后，设计提示词的视角会变：不再是"写一段好话"，而是"我该把什么放进上下文？放哪里？要不要沉淀成 Skill 复用？"——这正是本作业让我体会最深的一点。
  • 用边界提醒自己：上下文再大也有限、中间会"迷失"；Skill 再完善也要靠模型正确触发；Agent 再聪明也要有护栏。三者是协作关系，也是彼此的约束。
